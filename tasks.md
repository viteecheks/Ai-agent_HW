## Предложенные проверки (приёмочные сценарии)
- [ ] Стартовый набор: всего 8 ч, выполнено 2 ч, прогресс 25 %.
- [ ] WHEN включён фильтр «активные», THEN список меняется, прогресс остаётся 25 %.
- [ ] WHEN введено пустое название, THEN задача не добавляется, видна ошибка, данные формы сохранены.
- [ ] WHEN введены пустые часы, THEN задача не добавляется, видна ошибка, данные формы сохранены.
- [ ] WHEN введены отрицательные часы, THEN задача не добавляется, видна ошибка.
- [ ] WHEN введены часы вне диапазона или не кратные 0,5, THEN задача не добавляется, видна ошибка.
- [ ] WHEN все задачи удалены, THEN итог 0 ч, прогресс 0 %.
- [ ] WHEN «Практика» отмечена готовой, THEN выполнено 6/8, прогресс 75 %.
- [ ] WHEN «Практика» отмечена готовой и обратно снята, THEN возврат к 25 %.
- [ ] Интерфейс читаем на ширине 390 px, нет горизонтального скролла.
- [ ] Все поля и кнопки имеют подписи.
- [ ] При недоступном `localStorage` показано сообщение, приложение работает в памяти.
