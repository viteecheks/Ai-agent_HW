# proposal.md — Мини-трекер учебных задач на неделю

## Purpose
Создать автономный веб-мини-трекер для учёта учебных задач на неделю: добавление, удаление, отметка выполнения, подсчёт прогресса и фильтрация списка. Решение должно работать локально, без сети и внешних зависимостей.

## Goals
- Реализовать CRUD-операции над задачами (создание, удаление, переключение `done`).
- Корректно считать итоговые часы и прогресс выполнения.
- Поддерживать фильтр видимости без влияния на агрегаты.
- Обеспечить читаемый интерфейс на ширине 390 px без горизонтального скролла.
- Валидировать ввод (название, часы) и показывать ошибки рядом с полями, сохраняя введённые данные формы.

## Non-Goals (границы задачи)
- Не использовать CDN, внешние библиотеки и API-ключи.
- Не реализовывать серверную часть, синхронизацию между устройствами, авторизацию.
- Не выходить за рамки учебной недели: нет категорий, приоритетов, дедлайнов, экспорта.
- Не расширять модель задачи за пределы полей `id`, `title`, `hours`, `done`.

## Deliverables
- **Вариант A**: один файл `tracker-v2.html` с встроенными CSS и JavaScript.
- **Вариант B**: набор файлов `index.html`, `styles.css`, `app.mjs`, `domain.mjs`, `tests/acceptance.test.mjs`.

## Success Criteria
- Все приёмочные сценарии WHEN/THEN проходят.
- Интерфейс читаем на ширине 390 px.
- Приложение запускается открытием файла в браузере, без сборки и сети.
- При недоступном `localStorage` приложение продолжает работать в памяти с понятным сообщением.
