# design.md — Данные и расчёты

## Модель данных
Задача — объект с полями:
- `id` — уникальный идентификатор (строка или число, генерируется приложением).
- `title` — строка, непустая после `trim()`.
- `hours` — число, кратное 0,5, в диапазоне [0.5, 24].
- `done` — булево значение.

Состояние приложения:
- `tasks: Task[]` — текущий список задач.
- `filter: 'all' | 'active' | 'done'` — текущий фильтр видимости.
- `formState: { title: string, hours: string }` — сохранённые введённые данные формы.
- `storageAvailable: boolean` — флаг доступности `localStorage`.
